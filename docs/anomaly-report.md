# 异常报告

`loom-data check` 在导出数据上运行三条规则，把结果写成一份 JSONL 报告。运行方式见[使用说明](usage.md#检测异常)。

规则只读导出的 30 fps state 帧，不解码视频。默认阈值是待人工校准的初始值：没有异常记录不代表数据已验证正常。本检测也不替代导出格式校验。

## 报告格式

每行一条异常，对应一个时间区间。只记录位置和原因，不记录具体数值。

| 字段 | 含义 |
|---|---|
| `index` | episode 在数据集内的 `episode_index`，从 0 开始 |
| `stream` | `left_eef`、`right_eef`、`left_gripper`、`right_gripper` 之一 |
| `start_ns`、`end_ns` | 异常区间 `[start_ns, end_ns)`；单点异常两者相等 |
| `reason` | 规则标识：`boundary_idle`、`state_jump`、`internal_idle` |

```json
{"index":3,"stream":"left_eef","start_ns":0,"end_ns":4100000000,"reason":"boundary_idle"}
```

没有异常时报告是空文件。记录按 `episode_index` 排列，同一 episode 内按规则 1、2、3 排列。不同规则的记录不去重。

viewer 和 `anomaly-stats` 只依赖这五个字段，不依赖规则本身；出现新的 `reason` 时它们不用修改。

## 共用的定义

**时间**：第 `k` 帧的时刻为 `k/30` 秒，报告里取整到纳秒。episode 时间范围从 0 到最后一帧的时刻。四路 state 共用这条帧序列。

**变化**：两个样本之间，EEF 位置相差超过 1 cm 或朝向相差超过 5°，夹爪开合相差超过 0.05，就算发生了变化。位置用欧氏距离，朝向用 SO(3) 最短旋转角。这三个容差由三条规则共用。

无效数值、越界的开合值或无效旋转矩阵会使该 episode 检测失败。

导出数据经过 30 fps 重采样：异步源的位姿和夹爪做过插值，低帧率源（如 15 fps 的 Galaxea）的相邻帧之间是线性过渡。这会削弱原生数据里的单样本尖峰，规则 2 在这类数据上更不容易触发。

## 规则 1：首尾静止过长（`boundary_idle`）

对每一路流计算：

- 开头静止时长：从 episode 起点到该路第一次相对首样本发生变化的时刻；
- 结尾静止时长：从该路最后一次相对末样本发生变化的时刻到 episode 终点。

整段没有变化的流，两个时长都取整段时长。

四路取最小值：只要有一路在动，就认为 episode 已经开始或尚未结束，这样单臂长期不动不会被误判。

开头或结尾的静止时长超过 3 秒即为异常，分别记录 `[0, 开头静止时长)` 和 `[整段时长 − 结尾静止时长, 整段时长)`；两端都超时记两条。`stream` 取决定该端时长的那一路，多路并列时按 `left_eef`、`right_eef`、`left_gripper`、`right_gripper` 的顺序取第一路。

## 规则 2：孤立的单帧尖峰（`state_jump`）

只报告稳定上下文中的一个孤立样本。设该样本为 `b`，前后相邻样本为 `a`、`c`。位置、朝向、开合各自独立判断，同一个分量必须同时满足三项：

1. **跳出并恢复**：`min(d(a,b), d(b,c)) − d(a,c)` 严格超过尖峰幅度，默认位置 2 cm、朝向 10°、夹爪 0.25。减去 `d(a,c)` 是为了不把前后样本自身的漂移算进尖峰。
2. **前后一致**：`d(a,c)` 不超过变化容差。
3. **两侧稳定**：`a` 之前 100 ms 内的每个样本相对 `a` 都没有变化，`c` 之后 100 ms 内的每个样本相对 `c` 都没有变化。两侧各至少有 3 个不同的时间戳（含 `a`、`c`），时间轴要完整覆盖两个窗口，且两个窗口之间所有相邻采样间隔不超过 50 ms。

位置的跳出不能借朝向的稳定来通过。正常的单向快速运动、持续的阶跃、多帧偏移、有明显运动上下文的往返都不报告。规则不计算速度，也不累计多帧变化。

记录区间为 `[t_b, t_c)`。同一路中重叠或间隔不超过 50 ms 的区间合并；位置和朝向同时触发只记一条。

## 规则 3：中段静止过长（`internal_idle`）

规则 1 只管首尾，本规则管中间：四路同时不动的区间。

每一路以首样本为参考，依次比较后续样本；一旦相对参考发生变化，就把该样本的时刻记为变化时刻，并把参考更新为该样本。这样连续的小幅运动会累积到超过容差，不会因为单帧变化小而漏掉；容差内的往返噪声也不会被算成运动。

把四路的变化时刻合并排序。相邻两个变化时刻 `t_a < t_b` 之间，没有任何一路偏离自己的参考，所以 `[t_a, t_b)` 是四路同时静止的区间。`t_b − t_a` 超过 10 秒即为异常。

这样的区间两端都是变化时刻，所以总在 episode 中段。整段没有任何变化时不产生记录，那种情况由规则 1 报告。

区间是四路共同静止，没有哪一路能代表它，所以每个区间按四路各记一条，`start_ns = t_a`，`end_ns = t_b`。区间边界取首次超过容差的帧时刻，不代表精确的物理启停时刻。

## 阈值

都可以在 `loom-data check run` 或 `prepare` 上覆盖。

| 参数 | 默认 | 用途 |
|---|---|---|
| `--position-tolerance-m` | 0.01 | 位置的变化容差，米 |
| `--orientation-tolerance-deg` | 5 | 朝向的变化容差，度 |
| `--openness-tolerance` | 0.05 | 开合的变化容差 |
| `--max-boundary-idle-s` | 3 | 规则 1：首尾最长静止时间，秒 |
| `--position-jump-min-m` | 0.02 | 规则 2：位置尖峰的最小幅度，米 |
| `--orientation-jump-min-deg` | 10 | 规则 2：朝向尖峰的最小幅度，度 |
| `--openness-jump-min` | 0.25 | 规则 2：开合尖峰的最小幅度 |
| `--jump-max-duration-s` | 0.05 | 规则 2：允许的最大采样间隔，也是区间合并间隔，秒 |
| `--jump-context-s` | 0.1 | 规则 2：每侧的稳定窗口，秒 |
| `--max-internal-idle-s` | 10 | 规则 3：中段最长静止时间，秒 |

所有参数须有限且非负；`--jump-max-duration-s` 至少 1 ns，`--jump-context-s` 不小于它的两倍。
